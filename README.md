# Temple Rush

A lightweight browser-based endless runner inspired by classic temple-running games.

## Features

- 3-lane runner movement
- Jump and slide controls
- Random obstacle generation
- Coin collection and score system
- Increasing difficulty over time
- Keyboard and touch controls

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit: `http://localhost:8000`

## Controls

- Left / Right: `A`, `D`, arrow keys
- Jump: `W`, `Up`, `Space`
- Slide: `S`, `Down`
- Touch swipe: left/right/up/down
